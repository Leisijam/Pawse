## 一、产品概述

**Pawse** 是一款 macOS 菜单栏应用，帮助长时间使用电脑的用户养成规律休息的习惯。应用监测键盘/鼠标活动来计算专注使用时长，达到设定时长后会在全屏播放一段猫咪视频动画提醒用户休息，并记录每日使用与休息数据。

**一句话定位**：一个用可爱猫咪动画打断你、提醒你休息的屏幕使用时长管理工具。

### 核心价值主张

| 用户痛点 | Pawse 的解决方式 |
|---|---|
| 久坐/久盯屏幕不自知，容易忽略休息 | 后台自动计时，到点强提醒（全屏覆盖，不易忽略） |
| 普通计时器的提醒方式生硬、容易被直接划掉/忽略 | 用猫咪视频动画营造轻松氛围，提升被打断的接受度 |
| 专注工作/开会时不想被打扰 | 一键免打扰暂停提醒 |
| 想了解自己每天/每月实际用了多久电脑 | 「数据」Tab 展示今日与本月的时长、休息次数热力图 |
| 鼠标在移动但没有点击时被误判为空闲 | 基于系统级 `CGEventSource` 综合判断鼠标移动/键盘/点击/滚动，避免误暂停 |

## 二、目标用户

- 长时间使用 Mac 办公/学习的个人用户（程序员、设计师、学生等）
- 有意识管理久坐/用眼健康，但缺乏自制力主动休息的人群
- 偏好轻量、原生风格工具，不想使用臃肿的第三方效率软件

---

## 三、平台与技术基础

- **形态**：macOS 菜单栏应用（LSUIElement，无 Dock 图标）
- **技术栈**：SwiftUI + AppKit（`NSStatusItem` / `NSMenu` + 自定义 `NSView` / `AVPlayerLayer`）
- **构建方式**：Swift Package Manager（`swift build` / `swift run`），零外部依赖；附带一个备用 `Pawse.xcodeproj`
- **目标系统**：macOS 14.0+
- **数据存储**：本地持久化，无云同步、无账号体系
  - 设置：`UserDefaults`
  - 每日记录：JSON 文件（`~/Library/Application Support/Pawse/records.json`），保留最近 90 天
  - 自定义素材（视频/图片/头像）：同目录下的本地文件
  - 默认休息动画视频打包进 app 资源（`Sources/Resources/DefaultCat.mp4`），首次启动自动复制到应用支持目录，不依赖任何外部/桌面路径
  - 旧版本（PawBreak 时期）已保存的数据会在启动时自动从 `~/Library/Application Support/PawBreak/` 迁移到 `Pawse/`

## 四、功能需求（按当前实现）

### 4.1 菜单栏与主面板

- 菜单栏图标常驻，标题实时显示倒计时（如 `38:20`），使用等宽字体
- 点击图标弹出一个 400×400 的面板，通过 `NSMenu` + 自定义 `NSView`（`MenuItemView`）承载 SwiftUI 内容实现，**并非** SwiftUI 原生 `Popover`
  - 采用这种实现方式的原因：`NSPopover` 弹出时会激活 app，导致系统菜单栏被短暂隐藏；`NSMenu` 是系统标准菜单栏交互方式，不会触发这个问题
- 面板布局：左侧 72pt 宽侧边栏 + 右侧内容区
  - 侧边栏顶部：圆形头像，跟随系统深浅色模式自动切换日间/夜间素材；无自定义素材时显示默认猫咪 SF Symbol
  - 侧边栏下方：**3 个** Tab 图标 + 文字——「计时」「数据」「设置」，图标颜色随深浅色模式自适应

### 4.2 计时核心

- 状态机：`running`（计时中）/ `idle`（空闲暂停）/ `paused`（用户手动暂停）/ `onBreak`（休息中）
- 空闲检测使用 `CGEventSource.secondsSinceLastEventType`，分别查询鼠标移动、键盘、鼠标点击、滚轮四类事件的系统级最后触发时间，取最短间隔判断——**鼠标只移动不点击也会被视为活跃**，无需辅助功能权限
- 每秒 tick 一次：
  - 若判定为空闲（超过"空闲判定"设定时长无操作）→ 进入 `idle`，不计时也不保存新增时长
  - 若判定活跃 → 累加已用时长；达到"工作时长"阈值 → 触发休息
  - tick 中检测自然日变化，一旦跨天自动清零当日屏幕时长与休息次数
- 「计时」Tab：圆形进度环（随状态变色：进行中为强调色、空闲为橙色、暂停为灰色）+ 中央剩余时间 + 暂停/继续图标按钮（休息中禁用）
- 用户可手动暂停/继续（暂停会立即保存当前记录）
- 触发休息后设有 30 秒防抖，避免连续误触发

### 4.3 休息提醒（全屏猫咪）

- 达到工作时长后，为**每个连接的屏幕**各创建一个全屏透明窗口（`NSWindow`，level 为 `.screenSaver`，可跨 Space 显示）
- 窗口内容：
  - 全屏播放猫咪视频，使用 `AVPlayerLayer` 硬件解码渲染（早期实现用 `CVDisplayLink` + Core Image 逐帧转换，会在高分辨率视频下卡顿，已替换为 `AVPlayerLayer` 直接播放），保持宽高比居中显示（letterbox 区域透明，可透出桌面）
    - 若无视频则回退显示自定义静态图片
  - 左上角悬浮一个倒计时圆环（显示剩余休息秒数，随休息时长递减到 0 自动结束），配色随系统深浅色模式自适应（浅色模式白底黑字、深色模式深底白字，保证可读性）
- **跳过/结束方式**：点击倒计时圆环，或按 `Esc` 键，均可立即结束休息
  - ⚠️ 与早期需求文档「只能点击跳过按钮关闭猫咪，键盘按键无效」的设想不同，当前实现中 `Esc` 键可直接跳过
- 休息倒计时归零后自动结束（回到计时状态，已用时长清零重新开始）

### 4.4 免打扰模式

- 「设置」Tab 中的一个开关行（**并非独立 Tab**——早期设计规划的「免打扰」独立 Tab 已合并进设置项）
- 开启后：暂停活动空闲判定与计时增长，不触发休息提醒
- 关闭后：自动重置活动时间戳，避免误判为长时间空闲

### 4.5 设置

「设置」Tab 以列表形式提供以下可调项，均实时持久化到 `UserDefaults`，图标+文字左对齐、单行展示：

| 设置项 | 范围 | 默认值 |
|---|---|---|
| 工作时长 | 1–480 分钟 | 40 分钟 |
| 休息时长 | 1–60 分钟 | 5 分钟 |
| 空闲判定 | 1–60 分钟（存储为秒，60–3600 秒） | 2 分钟 |
| 免打扰 | 开关 | 关 |
| 开机自启 | 开关（`SMAppService.mainApp`） | 关 |
| 休息动画 | 选择本地视频文件替换默认猫咪视频 / 恢复默认 | 内置默认视频 |

- 「休息动画」支持**上传视频**（`.mov` / `.mp4`），通过独立可拖动的 `NSOpenPanel` 窗口选择（早期用 SwiftUI `.fileImporter`，会以 sheet 形式依附在小面板上、无法拖动且易与面板内容重叠误触，已改为独立面板）
- 上传成功/恢复默认后均有 2 秒的文字提示反馈（"已上传" / "已恢复"），提示消失后按钮本身保持常驻，不会消失
- 「恢复默认」不依赖任何外部文件路径——默认视频打包在 app 资源内，点击后从内置资源重新复制，稳定可靠
- ⚠️ 早期需求文档描述的「支持上传 JPG/PNG/GIF/Lottie JSON 图片素材」目前仅在数据层（`DataStore.saveCatImage/loadCatImage`）留有接口，**未在设置界面暴露**，也未接入休息覆盖层的实际展示逻辑（覆盖层仅在无视频时才回退到图片）
- ⚠️ 早期规划的默认动画方案「Lottie 矢量动画」未采用，实际使用内置 `DefaultCat.mp4` 视频文件，未引入 Lottie 依赖

### 4.6 数据统计

「数据」Tab 展示：

- **今日**：两张卡片——今日屏幕时长（`Xh Ym` 格式）、今日休息次数
- **本月**：两个热力图色块——本月累计屏幕时长 + 逐日热力图、本月累计休息次数 + 逐日热力图（颜色深浅按当日数值相对当月最大值的比例渲染，鼠标悬停可查看具体某天数值）
- 数据来源：本地 JSON 记录（每 60 秒自动落盘一次，暂停/休息/跨天触发时也会立即保存），最多保留 90 天
- ⚠️ `DailyRecord.sessions`（工作时段起止列表）字段已定义但当前逻辑未写入，为预留扩展字段

## 五、非功能需求

- **权限**：空闲检测使用 `CGEventSource` 系统级查询方式，无需辅助功能等额外系统权限
- **性能**：视频休息动画使用 `AVPlayerLayer` 硬件加速渲染，避免高分辨率视频下的卡顿；计时 tick 频率为 1 秒
- **稳定性**：不依赖任何外部第三方包；默认素材内置于 app 资源中，不依赖桌面文件或外部路径是否存在
- **数据延续性**：应用更名后自动从旧版本数据目录迁移用户设置与自定义素材，用户无感知
- **视觉风格**：黑白灰简洁配色，贴近 macOS 原生设置面板观感；系统 SF 字体；卡片圆角 8–10pt

## 六、与早期规划文档的主要差异汇总

| 项目 | 早期设想（`需求文档.md`/`设计规范.md`） | 当前实际实现 |
|---|---|---|
| 应用名称 | PawBreak（开发代号） | **Pawse**（正式定名） |
| 面板承载方式 | SwiftUI `Popover`，320×420pt | `NSMenu` + 自定义 `NSView`，400×400pt |
| Tab 数量与结构 | 4 个 Tab（计时/免打扰/数据/设置） | 3 个 Tab（计时/数据/设置），免打扰并入设置 |
| 默认休息动画方案 | Lottie 矢量动画 | 内置 MP4 视频，`AVPlayerLayer` 硬件解码播放 |
| 自定义素材上传格式 | JPG/PNG/GIF/Lottie JSON | 仅视频文件（图片上传接口已写但未接入 UI），独立可拖动窗口选择 |
| 跳过休息交互 | 仅允许点击「跳过」按钮，键盘无效 | 点击倒计时圆环 或 按 `Esc` 键均可跳过 |
| 侧边栏顶部 | 固定猫咪图标 | 可自定义日间/夜间头像图片，随系统深浅色切换 |
| 数据展示 | 单一日历热力图 | 「今日」卡片 + 「本月」双热力图（时长/休息次数分开） |
| 空闲检测方式 | CGEvent 全局监听（需辅助功能权限） | `CGEventSource` 系统级查询（无需权限），综合判断鼠标移动/点击/键盘/滚动 |

> 早期规划文档中「有意识的产品优化」（如 Esc 快捷跳过、双热力图、免打扰并入设置）已在实践中验证有效，予以保留；「未完成的遗留任务」详见下方已知问题。

## 七、已知问题 / 技术债

1. 自定义图片休息动画（`DataStore.saveCatImage` / `loadCatImage`）有数据层实现，但设置界面未提供图片上传入口，功能不完整。
2. `DailyRecord.sessions` 字段未被写入，「工作时段」明细目前无法追溯，历史数据只有汇总时长/次数。
3. 休息跳过支持 `Esc` 键，与最初"防止误触"的设计初衷存在冲突，属于有意的产品调整（提升可用性），非 bug。
4. `Pawse.xcodeproj` 为早期手工维护的工程文件，文件列表可能滞后于 `Sources/` 实际内容，日常开发以 `swift build` / `swift run` 为准，不依赖该工程文件的准确性。
