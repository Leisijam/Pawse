# Pawse — 设计规范

> ⚠️ 本文档为立项初期规划稿，作为历史存档保留。整体黑白灰风格与核心配色原则仍然适用；尺寸、Tab 数量等细节已随实际开发调整，具体现状请参阅 [docs/PRD.md](PRD.md)。

## 色彩系统

| 用途 | 色值 |
|------|------|
| 主背景 | `Color(nsColor: .windowBackgroundColor)` |
| 次背景 | `Color(nsColor: .controlBackgroundColor)` |
| 主文字 | `Color.primary` |
| 次文字 | `Color.secondary` |
| 强调色 | `Color.accentColor`（系统蓝） |
| 分割线 | `Color.secondary.opacity(0.2)` |

## 字体

- 全部使用系统 SF 字体
- 标题：`.font(.headline)`
- 正文：`.font(.body)`
- 数字/时长：`.font(.system(size: 28, weight: .medium, design: .monospaced))`
- 小字/标签：`.font(.caption)`

## 尺寸

| 元素 | 尺寸 |
|------|------|
| Popover 总尺寸 | 320 × 420 pt |
| 侧边栏宽度 | 72 pt |
| 侧边栏图标 | 28 × 28 pt |
| 内容区内边距 | 16 pt |
| 圆角 | 8 pt（卡片）、12 pt（按钮） |

## 图标

- 使用 SF Symbols 系统图标
- 计时：`timer`
- 免打扰：`moon.zzz.fill`
- 数据：`calendar`
- 设置：`gearshape`
- 猫咪占位：`cat.fill`

## 布局原则

- 左侧垂直侧边栏，右侧内容区
- 侧边栏顶部猫咪图标，居中显示
- 四个 Tab 图标垂直排列，当前选中高亮（accentColor 背景）
- 内容区顶部标题，下方对应内容

## 动效

- Tab 切换：内容区淡入淡出
- 进度环：平滑动画
- 开关：系统默认 Toggle 动效
