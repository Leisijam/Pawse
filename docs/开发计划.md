# Pawse — 开发计划

> ✅ 本文档记录的 5 个阶段已于 2026-07-12 全部完成（详见 [开发日志.md](../开发日志.md)）。
> 部分验收项在后续迭代中被调整或替换（如 Lottie 动画未采用、免打扰并入设置 Tab），当前准确状态以 [docs/PRD.md](PRD.md) 为准，本文件仅作立项初期规划的历史存档。

## 总体原则

- 分 5 个阶段推进，每个阶段完成后验证通过再进入下一阶段
- 每次只做一个阶段，不跨阶段混合开发
- 每个阶段结束：代码可编译运行，功能可体验

---

## 阶段 1：项目骨架

**目标**：Xcode 项目可编译运行，菜单栏图标可点击，弹出面板有侧边栏 + 4 个 Tab 的骨架

**文件**：
- `App.swift`
- `Views/MenuBarView.swift`
- `Views/TimerTab.swift`
- `Views/DNDTab.swift`
- `Views/HistoryTab.swift`
- `Views/SettingsTab.swift`

**验收**：
- [ ] 应用在菜单栏显示图标
- [ ] 点击图标弹出 Popover 面板
- [ ] 左侧侧边栏，顶部猫咪图标 + 4 个 Tab
- [ ] 点击 Tab 切换右侧内容
- [ ] 设计风格黑白灰，符合设计规范

---

## 阶段 2：计时核心

**目标**：能够检测用户活动、计时、在菜单栏显示倒计时

**文件**：
- `Managers/ActivityMonitor.swift`
- `Managers/TimerManager.swift`
- `Models/AppSettings.swift`

**验收**：
- [ ] 菜单栏显示倒计时（如 "38:20"）
- [ ] 键盘/鼠标活动可被检测
- [ ] 超时无操作后暂停计时
- [ ] 计时器每 1 秒更新一次

---

## 阶段 3：休息提醒

**目标**：达到工作时长后弹出全屏猫咪窗口

**文件**：
- `Managers/BreakWindowManager.swift`
- `Views/BreakOverlayView.swift`
- 添加 Lottie 依赖

**验收**：
- [ ] 达到设置的工作时长后触发
- [ ] 全屏窗口覆盖所有内容
- [ ] 猫咪动画播放（默认 Lottie）
- [ ] 显示"该休息了"提示
- [ ] 只有点击"跳过"按钮才能关闭
