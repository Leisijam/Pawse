# Pawse — 屏幕时长计时器 完整需求 & 设计方案

> ⚠️ 本文档为立项初期（2026-07-10）规划稿，作为历史存档保留。部分内容（如免打扰 Tab、Lottie 动画方案）已在开发中调整，当前实际实现请参阅 [docs/PRD.md](PRD.md)。

## 项目概述

一款 macOS 菜单栏应用（工作名：**Pawse**），用 SwiftUI 开发。监测键盘/鼠标活动来判断屏幕使用时长，超时后用全屏猫咪动画提醒休息——猫咪从屏幕侧边走出来坐下，带有呼吸、摇尾巴等自然动态。设计风格简洁黑白灰，贴近原生 macOS 风格。

## 一、核心决策（已确认）

| 决策项 | 选择 |
|--------|------|
| 开发技术 | SwiftUI（macOS 原生） |
| 应用形态 | 菜单栏 App（右上角小图标） |
| 屏幕使用判断 | 检测键盘/鼠标活动，无操作超时暂停计时 |
| 休息提醒行为 | 允许跳过（按键或点击关闭猫咪，计时器不清零） |
| 无操作判定时长 | 用户可自定义 |
| 开机自启 | 是 |
| 免打扰模式 | 纯手动开关 |

## 二、功能模块

### 模块 1：计时核心 + 休息提醒

- 菜单栏显示倒计时图标/文字（如 "32:08"）
- 使用 CGEvent 监听键盘/鼠标活动
- 用户可设置：
  - 工作时长（默认 40 分钟）
  - 休息时长（默认 5 分钟）
  - 无操作判定时间（默认 2 分钟）
- 达到工作时长 → 全屏猫咪动画覆盖屏幕
  - 猫咪从屏幕侧边（右侧）走入，走到屏幕中央坐下
  - 伴随呼吸起伏、尾巴轻摇等自然动态
  - 默认使用 Lottie 矢量动画（免费素材，文件小，缩放不失真）
- **只能点击"跳过"按钮关闭猫咪**，键盘按键无效，防止误触
- 休息期间用户未点击跳过，则继续休息状态（检测到活动也无妨，不自动结束）

### 模块 2：免打扰模式

- 菜单栏面板中一键开关
- 开启后：计时器暂停，不弹出休息提醒
- 关闭后：计时器恢复，从暂停处继续
- 菜单栏图标在免打扰模式下有视觉区分（如变色/加标记）

### 模块 3：数据汇总

- 今日统计：总屏幕时长、站立/休息次数
- 日历视图：按天查看历史记录
- 数据本地持久化存储

### 模块 4：自定义

- 上传本地图片/GIF 替换默认猫咪
- 支持 JPG / PNG / GIF / Lottie JSON
- 实时预览上传的猫咪素材
- 默认提供 Lottie 猫咪动画（走入 + 坐下 + 呼吸摇尾）

## 三、界面布局

菜单栏点击后弹出面板（Popover），左右分栏布局：

```
┌──────┬──────────────────────────┐
│        │                          │
│  🐱   │                          │
│        │    当前 Tab 内容区域       │
│ ───── │                          │
│ 计时   │                          │
│ 免打扰 │                          │
│ 数据   │                          │
│ 设置   │                          │
│        │                          │
└──────┴──────────────────────────┘
  左侧      右侧内容区
  边栏
```

- **左侧边栏**：顶部猫咪图标 → 四个 Tab 图标/文字（计时 / 免打扰 / 数据 / 设置）
- **右侧内容区**：显示当前选中 Tab 的详细内容

### Tab 1：计时
- 圆形进度环 + 剩余时间数字
- 当前状态文字（工作中 / 休息中 / 已暂停）
- 快速开始/暂停按钮

### Tab 2：免打扰
- 大开关按钮
- 免打扰状态说明

### Tab 3：数据
- 今日总时长 + 休息次数
- 简易日历热力图

### Tab 4：设置
- 工作时长选择器
- 休息时长选择器
- 无操作判定时间
- 上传猫咪图片按钮 + 预览

## 四、技术架构

```
MyFirstApp/
├── App.swift                   # 入口，配置菜单栏
├── Managers/
│   ├── TimerManager.swift      # 计时核心逻辑
│   ├── ActivityMonitor.swift   # CGEvent 监听键盘鼠标
│   ├── BreakWindowManager.swift # 全屏猫咪窗口管理
│   ├── DNDManager.swift        # 免打扰状态管理
│   └── DataStore.swift         # 数据持久化（UserDefaults + JSON）
├── Models/
│   ├── AppSettings.swift       # 用户设置模型
│   └── DailyRecord.swift       # 每日记录模型
├── Views/
│   ├── MenuBarView.swift       # 菜单栏点击后的弹出面板
│   ├── TimerTab.swift           # 计时 Tab
│   ├── DNDTab.swift            # 免打扰 Tab
│   ├── HistoryTab.swift        # 数据 Tab
│   ├── SettingsTab.swift       # 设置 Tab
│   └── BreakOverlayView.swift  # 全屏猫咪覆盖层
├── Assets.xcassets             # 图标、默认猫咪图片
└── Info.plist                  # 应用配置
```

### 关键技术点

- **CGEvent 监听**：全局监听键盘/鼠标事件，时间戳记录最后活动时间
- **菜单栏图标**：`NSStatusBar` + `NSStatusItem`，显示倒计时或状态图标
- **全屏覆盖窗口**：独立 `NSWindow`，level 设为 `.screenSaver` 级别覆盖所有窗口
- **数据存储**：UserDefaults 存设置，JSON 文件存每日记录（简单可靠）
- **开机自启**：`SMAppService.mainApp.register()` （macOS 13+）
