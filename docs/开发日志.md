# 开发日志

## 2026-08-13 — 应用更名为 Pawse + 迭代打磨

### 已完成
- [x] **应用正式更名**：PawBreak → **Pawse**
  - 项目文件夹、Swift Package 名称、Xcode 工程、App 结构体名全部重命名
  - 应用支持目录从 `~/Library/Application Support/PawBreak/` 迁移到 `Pawse/`，启动时自动搬运旧数据，用户无感知
  - 全部文档（PRD、需求文档、技术方案、设计规范、开发计划、CLAUDE.md）同步更新应用名
- [x] **休息动画大幅优化**
  - 播放引擎从「`CVDisplayLink` + Core Image 逐帧转换」改为 `AVPlayerLayer` 硬件解码，解决高分辨率视频卡顿问题
  - 默认视频改为打包进 app 资源（`Resources/DefaultCat.mp4`），不再依赖任何外部/桌面路径，「恢复默认」100% 可靠
  - 上传视频改用独立可拖动的 `NSOpenPanel`，替代会与小面板重叠、无法拖动的 SwiftUI `.fileImporter`
  - 倒计时圆环移到左上角、放大尺寸，配色随深浅色模式自适应（不再出现浅色模式下看不清的问题）
  - 支持按 `Esc` 键跳过休息
- [x] **空闲检测重写**：从 `CGEvent` 全局监听改为 `CGEventSource` 系统级查询，解决「鼠标在移动但未点击时被误判为空闲」的问题，且不再需要辅助功能权限
- [x] **菜单栏面板重构**：从 `NSPopover` 改为 `NSMenu` + 自定义 `NSView`，解决弹出面板时系统菜单栏被隐藏的问题
- [x] **数据统计改版**：从「7 天柱状图」改为「今日摘要 + 本月双热力图（屏幕时长/休息次数分开）」
- [x] **界面精简**：免打扰并入设置 Tab（原 4 Tab 精简为 3 Tab：计时/数据/设置）；侧边栏头像可自定义日夜间素材；清理未使用的 `DNDTab.swift` 死代码
- [x] **跨天数据自动重置**：过午夜后今日屏幕时长/休息次数自动清零

### 已知问题
- 图片休息动画数据层接口已实现但设置界面未暴露入口
- `DailyRecord.sessions` 字段未写入，暂无法追溯具体工作时段明细
