# Pawse — 技术方案

> ⚠️ 本文档为立项初期规划稿，作为历史存档保留。实际实现中面板承载方式、空闲检测方式、视频播放方案均有调整，当前准确的技术实现请参阅 [docs/PRD.md](PRD.md)。

## 技术栈

| 层级 | 选型 |
|------|------|
| 语言 | Swift 5.9+ |
| UI 框架 | SwiftUI |
| 目标系统 | macOS 14.0+ |
| 依赖管理 | Swift Package Manager |
| 动画引擎 | Lottie (Airbnb) |
| 数据存储 | UserDefaults（设置）+ JSON 文件（历史记录） |

## 架构

```
App.swift                     → @main 入口，配置 NSStatusItem
  └── MenuBarView.swift       → Popover 容器（侧边栏 + 内容区）
        ├── TimerTab.swift     → 计时 Tab
        ├── DNDTab.swift       → 免打扰 Tab
        ├── HistoryTab.swift   → 数据 Tab
        └── SettingsTab.swift  → 设置 Tab
```

### Manager 层（@Observable / @StateObject）

| 模块 | 职责 |
|------|------|
| `TimerManager` | 计时状态机（运行/暂停/空闲/休息），超时触发 |
| `ActivityMonitor` | CGEvent 全局监听键盘/鼠标，判断用户是否活跃 |
| `BreakWindowManager` | 管理全屏猫咪窗口的生命周期 |
| `DNDManager` | 免打扰状态开关 |
| `DataStore` | 设置读写（UserDefaults），历史记录读写（JSON 文件） |

### Model 层

| 模型 | 字段 |
|------|------|
| `AppSettings` | workDuration, breakDuration, idleTimeout, customCatPath, enableAutoLaunch |
| `DailyRecord` | date, totalScreenTime, breakCount, sessions: [Session] |
| `Session` | startTime, endTime, duration |

## 关键 API

### 菜单栏
```swift
NSStatusBar.system.statusItem(with:)
NSStatusItem.button?.title = "32:08"
NSPopover + NSHostingView 承载 SwiftUI 视图
```

### 活动监听
```swift
CGEvent.tapCreate(tap: .cgSessionEventTap, place: .headInsertEventTap, 
                  options: .listenOnly, eventsOfInterest: eventMask, ...)
// 监听: keyDown, leftMouseDown, rightMouseDown, mouseMoved, scrollWheel
```

### 全屏覆盖窗口
```swift
NSWindow(contentRect: NSScreen.main!.frame, styleMask: .borderless, ...)
window.level = .screenSaver
window.collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]
```

### 开机自启
```swift
SMAppService.mainApp.register()  // macOS 13+
```

### 数据持久化
- UserDefaults：`AppSettings` Codable
- 历史记录：`~/Library/Application Support/Pawse/records.json`

## 安全权限

- **辅助功能权限**：CGEvent 监听需要用户在「系统设置 → 隐私与安全性 → 辅助功能」中授权
- **文件访问**：NSOpenPanel 用于用户选择猫咪图片
